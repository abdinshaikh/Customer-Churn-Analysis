# Customer Churn Analysis

Customer churn analysis using Python,EDA, customer segmentation, and Power BI.

## Project Overview

This project analyzes telecom customer data to understand customer churn patterns and identify factors associated with customer retention and churn.

The project includes data cleaning, exploratory data analysis, customer segmentation, and an interactive Power BI dashboard.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Power BI

## Project Files

- `customer_segm_analysis.ipynb` - Data analysis, visualization, and customer segmentation
- `Customer_churn.pbix` - Interactive Power BI dashboard
- `Telco_Customer_Churn_Dataset.csv` - Dataset used for the analysis

## Dashboard

The Power BI dashboard provides an interactive view of customer churn across contract type, tenure, internet service, payment method, and other customer attributes.
